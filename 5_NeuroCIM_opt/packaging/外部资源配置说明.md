# NeuroCIM 内置资源说明

Windows 完整发布包已经包含软件运行所需的网络模型、数据集和器件测量数据，解压后双击 `NeuroCIM/NeuroCIM.exe` 即可启动，无需另外下载 Python、模型 checkpoint 或数据集。

内置资源包括：

- LeNet-5 / MNIST
- BNN / MNIST
- ResNet-20 / CIFAR-10
- TinyTransformer（CCT-7/3x1）/ CIFAR-10
- ResNet-8 / MNIST
- MobileNetV2 x1.0 / CIFAR-10
- VGG11-BN / CIFAR-10
- SqueezeNet 1.1 / CIFAR-10
- GPT-2 Small 文本生成模型及 tokenizer
- MNIST 完整训练集与测试集
- CIFAR-10 完整训练集与测试集
- `0_data` 中的五组器件乘法测量 CSV
- NeuroSim PPA 可执行程序及其 Windows 运行库

软件首次打开时，“误差建模与阵列分析”页面默认选择内置的 `03_AOS_1.csv`。完成误差拟合后，在“网络与数据集”页面勾选模型；单样本推理、批量推理和误差感知训练会自动使用该模型对应的内置数据集与 checkpoint。

如果需要使用自己的资源，仍可在 GUI 中重新选择路径，也可以使用以下环境变量覆盖内置目录：

- `NEUROCIM_DATA_ROOT`
- `NEUROCIM_MNIST_ROOT`
- `NEUROCIM_CIFAR10_ROOT`
- `NEUROCIM_OUTPUT_ROOT`
- `NEUROCIM_NEUROSIM_BIN`
- `NEUROCIM_CONFIG`
