# 通用神经网络误差注入软件需求说明（文件中代码仅作参考）

## 1. 项目目标

开发一套面向 PyTorch 神经网络模型的通用误差注入软件。用户导入已有模型后，软件自动识别模型中的常用计算层，并将其替换为支持误差注入的自定义层。

误差统一注入到**每一层的输出特征图（Output Feature Map）**。正常推理时关闭误差模块，保证模型按照原始计算方式运行；误差推理时开启误差模块，将已有的误差模型作用于各层输出特征图，再将带误差的特征图传递给下一层，从而评估误差对整个神经网络推理结果的影响。

整体流程：

```text
模型导入
  ↓
自动识别模型层
  ↓
替换为自定义 Fault Layer
  ↓
正常计算该层输出特征图
  ↓
根据 fault_enable 决定是否调用误差模型
  ↓
将正常/带误差特征图输入下一层
  ↓
完成模型推理及结果统计
```

---

## 2. 模型导入

支持 PyTorch 模型，能够导入常见的模型结构及权重文件。

建议支持：

- `torch.nn.Module` 模型；
- `.pth` / `.pt` 模型或权重文件；
- 常见 CNN、MLP 、Transformer、SNN等网络结构。

后续可根据需要扩展 ONNX 等模型格式。

---

## 3. 自动层识别与替换

软件导入模型后，需要自动递归遍历模型结构，识别指定类型的 PyTorch 层，例如：

- `torch.nn.Conv2d`
- `torch.nn.Linear`

并将其替换为对应的自定义误差注入层，例如：

```text
torch.nn.Conv2d
        ↓
FaultConv2d

torch.nn.Linear
        ↓
FaultLinear
```

替换时需要完整保留原始层的权重、Bias、Stride、Padding、Kernel Size、Groups 等参数，保证自定义层与原始层具有相同的正常计算功能。

例如：

```python
fault_model = faultify(original_model)
```

自动转换过程：

```text
原始 PyTorch Model
        ↓
递归扫描 model.named_children()
        ↓
识别支持替换的 Layer
        ↓
建立对应 Fault Layer
        ↓
复制原始 Layer 参数和权重
        ↓
返回支持误差注入的新模型
```

---

## 4. 自定义误差层

自定义层应尽量兼容原始 PyTorch Layer，并增加：

```python
fault_enable
error_model
```

两个基本接口。

以卷积层为例：

```python
class FaultConv2d(nn.Conv2d):

    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)

        self.fault_enable = False
        self.error_model = None

    def forward(self, x):

        # 原始卷积计算
        output = super().forward(x)

        # 在输出特征图上注入误差
        if self.fault_enable and self.error_model is not None:
            output = self.error_model(output)

        return output
```

因此：

正常推理时：

```python
fault_enable = False
```

计算流程：

```text
Input
  ↓
Conv / Linear
  ↓
Output Feature Map
  ↓
Next Layer
```

误差推理时：

```python
fault_enable = True
```

计算流程：

```text
Input
  ↓
Conv / Linear
  ↓
Output Feature Map
  ↓
已有误差模型
  ↓
Faulty Output Feature Map
  ↓
Next Layer
```

## 5. 自动模型转换

需要实现统一的模型转换函数，用于自动将原始 PyTorch Layer 替换成对应的 Fault Layer。

例如：

```python
def replace_layers(module):

    for name, child in module.named_children():

        if isinstance(child, nn.Conv2d):

            new_layer = FaultConv2d(
                child.in_channels,
                child.out_channels,
                child.kernel_size,
                child.stride,
                child.padding,
                child.dilation,
                child.groups,
                child.bias is not None,
                child.padding_mode
            )

            new_layer.load_state_dict(child.state_dict())

            setattr(module, name, new_layer)

        elif isinstance(child, nn.Linear):

            new_layer = FaultLinear(
                child.in_features,
                child.out_features,
                child.bias is not None
            )

            new_layer.load_state_dict(child.state_dict())

            setattr(module, name, new_layer)

        else:
            replace_layers(child)
```

后续可以继续扩展其他 PyTorch Layer 的自动替换。

---

## 6. 统一误差控制

软件需要提供统一的控制接口，用于开启或关闭整个模型或者指定层的误差注入。

建议设计：

```python
controller = FaultController(model)
```

正常推理：

```python
controller.disable_all()
```

误差推理：

```python
controller.enable_all()
```

同时建议支持指定层开启误差，例如：

```python
controller.enable(
    layers=[
        "layer1.0.conv1",
        "layer2.0.conv2"
    ]
)
```

或者按层类型控制：

```python
controller.enable(layer_type="Conv2d")
```

误差模型由外部提供，并通过统一接口加载到需要注入误差的 Fault Layer 中。

例如：

```python
controller.set_error_model(error_model)
```

---

## 7. 推理模式

软件至少支持两种推理方式。

### 正常推理

关闭所有 Fault Layer 的误差使能：

```python
controller.disable_all()

output = model(x)
```

用于获得模型基准推理结果。

### 带误差推理

开启指定 Fault Layer 的误差使能：

```python
controller.enable_all()

output_fault = model(x)
```

此时每个启用误差的 Layer 按照以下方式计算：

```text
Layer Input
   ↓
原始 Layer 计算
   ↓
Output Feature Map
   ↓
Error Model
   ↓
Faulty Feature Map
   ↓
Next Layer
```
